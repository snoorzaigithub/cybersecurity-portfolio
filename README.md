# Cybersecurity Projects & Hands-On Labs

## About This Portfolio

Welcome to my cybersecurity portfolio. This repository documents my hands-on lab work and practical learning in cybersecurity, Linux system administration, cryptography, password security, rootkit investigation, and network security monitoring.

The purpose of this portfolio is to demonstrate my technical learning, document the tools and techniques I have explored, and showcase practical experience gained through cybersecurity coursework and lab exercises.

## Skills & Areas of Study

- **Linux System Administration:** Virtual machine configuration, SSH, DNS, and Linux service management
- **Network Services:** Apache, MySQL, and PHP installation and configuration
- **Cryptography:** Symmetric and asymmetric encryption, encryption modes, and OpenPGP
- **Public Key Infrastructure (PKI):** Public-key cryptography and certificate-related concepts
- **Password Security:** Password-cracking techniques and password security concepts
- **System Integrity & Rootkit Investigation:** Integrity checking and investigation of potential rootkit indicators
- **Network Security:** Snort intrusion detection and firewall configuration

## Labs Included

### 1. Cloud Environment and Virtual Machine Configuration
- Connected to a cloud-based lab environment using Jetstream.
- Worked with virtual machine configuration and management.
- Practiced basic environment setup and system administration.

### 2. Linux Configuration and Network Services
- Configured a Linux virtual machine.
- Worked with SSH and DNS settings.
- Installed and configured web and database services, including Apache, MySQL, and PHP.
- Explored user permissions and restricted administrative privileges.

### 3. Symmetric and Asymmetric Cryptography
- Explored symmetric and asymmetric encryption.
- Studied encryption modes and their characteristics.
- Practiced fundamental cryptographic operations.

### 4. OpenPGP
- Explored OpenPGP and its role in protecting information.
- Studied public-key encryption, digital signatures, and secure communication concepts.

### 5. Public Key Infrastructure (PKI)
- Studied public-key cryptography and PKI concepts.
- Explored the role of digital certificates and trust in secure communications.

### 6. Password Cracking and Password Security
- Practiced password-cracking techniques in a controlled lab environment.
- Explored password weaknesses and the importance of strong password policies.

### 7. Rootkit Investigation and System Integrity Checking
- Investigated potential rootkit indicators in a Linux environment.
- Used system investigation and integrity-checking tools.
- Explored tools such as Tripwire, chkrootkit, rkhunter, unhide, and tshark.
- Documented observations and findings from the investigation.

### 8. Intrusion Detection with Snort and Firewall
- Explored Snort as a network intrusion detection system.
- Practiced firewall configuration and network traffic monitoring.
- Studied how intrusion detection and firewall rules can contribute to network defense.
